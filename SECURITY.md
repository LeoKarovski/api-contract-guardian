# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

For security-sensitive issues, contact the project maintainer privately with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any relevant logs or proof of concept

Please avoid including secrets, credentials, tokens, or other sensitive information in reports.

## Supported versions

Security fixes will be prioritized for the latest released version.

Older versions may not receive security updates.
